# DSH Desktop Center · 安全边界

## 当前权限

仅使用受限的 `stat`、`readdir`、`realpath`、`readFile` 检查经核实的 Desktop/Skills 路径。不会访问账号会话、Cookie、Token 或 Keychain；不会执行 Skill 脚本、外部命令或未授权网络请求；不会修改目标 Desktop 配置。

## 扫描安全要求

- 对 `SKILL.md`、Skill 整包及目录遍历设定大小/数量限制；越界软链接和无法检查的文件返回 `unknown`。
- 权限拒绝、应用未安装和未知路径均保留诊断，不当作成功、空列表或错误的在线状态。
- API 仅支持经 DSH 认证的只读 GET，不在响应中回显原始异常堆栈、凭据或敏感文件内容。
- UI 明确区分真实数据与演示数据，不把应用安装与已登录/已连接混淆。
- 更高权限的签到、积分、安装、同步、MCP 修改或桌面控制应另建独立插件和安全模型，本项目不提前开启。

## 报告漏洞

不要在公开 Issue 中粘贴个人账号、用户目录或敏感原始日志；请按照仓库根目录 `SECURITY.md` 的流程披露。
