# 安全与可靠性要求

## 当前执行路径

仅 `stat`, `readdir`, `realpath`, `readFile` 对候选应用目录和 `SKILL.md` 执行只读操作；无外网请求、无子进程、无系统自动化权限调用、无写入目标 Desktop 配置。扫描 Skill 最大 64 KiB；软链接若指向 home 外则跳过。错误消息只输出代码，不带文件内容。

## 后续写入系统的最低要求

1. 对每个目标生成变更计划（文件路径、内容 hash、修改范围、应用范围、风险），不得“批量全选默认允许”。
2. 用户按 Desktop 和具体技能逐一授权，使用本地密钥存储管理服务端 Token。
3. 部署前校验原始文件未发生并发变更；先备份，写临时文件，fsync，再原子替换。必要时对并发启动的桌面软件采取协调机制。
4. 如果文件变化竞争或任何验证失败，拒绝写入并恢复原状。
5. 禁止自动执行未审核的 MCP Server、Skill scripts、Agent hooks；未知配置应当原样保留。
6. 账号相关自动化先查平台政策；若存在验证码/人工验证，不自动破解；自动时间仅在规则允许的时间内变化。
7. 不把 Cloud/CLI 账户当作 Desktop 同一会话；能力查询失败必须显式报 `unsupported`。
8. 不把积分预测当成官方到账记录；所有到期日保留来源与最后核验时间。
