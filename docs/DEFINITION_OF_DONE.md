# DEFINITION OF DONE · 完成定义

**状态不是一个布尔值。** 每个插件在 issue / PR / 发布记录中必须注明状态、证据以及未完成项。

| 状态 | 必须具备的客观证据 | 不允许声明 |
|---|---|---|
| `designed` 设计完成 | 边界、契约草案、威胁模型、主要用例与不做项获评审 | 功能可用 |
| `code-complete` 代码完成 | 代码、测试、版本变化记录；离线门禁全绿；质量工具结果记录 | 已兼容真实 DSH / Desktop |
| `integration-verified` 集成完成 | 在指定真实 DSH Host 和 macOS 上安装/重载/关闭/卸载验证，记录版本及证据 | 所有机器兼容 |
| `release-ready` 可发布 | 下列质量门禁与视觉验收（有 UI 时）均过、无阻断缺陷、升级回滚已验证 | 不受支持的平台已支持 |

## 单个需求的验收结构

1. **可观察行为**：给定环境、操作和期望输出（Given/When/Then），至少一条正常、异常与无权限路径。
2. **接口与隔离**：不会修改无关 Bundle；Provider 丢失后 Consumers 有明确失败/降级行为。
3. **数据正确**：区分已验证、推断、未知；时间、时区、有效期都标来源与观察时间。
4. **安全**：默认最小权限，不记录秘钥，不执行下载的 Skill/MCP 脚本，所有写入可预览和撤销。
5. **运行可靠**：重试具有界限、定时任务可幂等恢复、资源/事件在插件卸载时释放。
6. **UI（若有）**：连接真实数据，包含正常/空/加载/错误/权限不足/离线/过期状态；深浅主题和键盘操作验收。
7. **可核验证据**：测试命令、结果、环境版本、截图/日志路径、残余风险与未验证项。

## 本项目截至 V0.2 的状态

- Desktop Registry：只读模拟测试通过；**无 Mac DSH 实机验证**；最多 `code-complete` 的部分证据。
- Skills Hub：完整包指纹、未知状态和测试；**无 Mac DSH 实机验证**；最多 `code-complete` 的部分证据。
- MCP Hub / Plugin Hub / Check-in / Credits / Bridge / SuperAgent：仅为契约/规划，**不是已开发**。
- UI：V0.2 未实现实际 DSH Client 面板；任何概念图不得冒充真实 UI。

发布前必须根据 `docs/QUALITY_GATES.md` 逐项证明，不允许 Agent 自行把“测试通过”改成“正式完成”。
