## 评审检查

- [ ] 统一字体、边距、圆角与组件状态；无不必要的装饰
- [ ] 页面层级、命名、主要任务路径清晰
- [ ] 正常、空、加载、错误、权限拒绝、离线及未知状态完整
- [ ] 不将发现安装路径等同账号已登录；目录存在不等于客户端正在运行
- [ ] 键盘访问、焦点顺序、标签、对比度和减少动效
- [ ] 深/浅主题，窄/宽布局，没有遮挡或溢出
- [ ] Unslop 提出的问题和修改记录（或明确不适用）
- [ ] 花叔设计方向与最终页面一致（或变更经过确认）
- [ ] 真实交互验证通过，没有用静态原型冒充可用页面
