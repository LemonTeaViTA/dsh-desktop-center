# DSH Desktop Center 任务清单

以 macOS DSH Desktop 为验收环境。发现和比较默认只读。安装、卸载及配置写入由用户选择目标并确认，按应用逐个验证。每项验收通过后勾选，发布记录见 [CHANGELOG.md](CHANGELOG.md)。

- [x] **Desktop 发现与详情**。在 DSH 中识别并查看八个应用目标。
- [x] **Skills 浏览与比较**。支持分组、简介搜索、跨端对比、刷新和诊断。
- [x] **Qoder 单端 Skills 命令**。两版独立安装、同名保护、可恢复卸载，已在本机实测。
- [x] **DSH 面板单端管理 Skills**。两版均验证原生选目录、确认安装、冲突、取消及可恢复卸载。Qoder 两版 0.5.11 在已安装 Skills 中显示各自的测试 Skill，卸载并刷新后记录消失。
- [x] **Skills 批量管理**。独立 DSH 已验证原生选目录、两版批量安装、批量卸载、逐目标结果和部分失败重试。
- [x] **MCP 单端配置管理**。两版均验证添加、取消、移除及刷新。Qoder 两版 0.5.11 加载各自的本机 MCP 并列出测试工具，移除后记录消失，配置文件与测试前逐字节一致。
- [x] **MCP 多端管理**。Qoder 两版共用批量入口。独立 DSH 已验证逐端结果、不兼容配置原样保留、仅重试失败目标、取消及批量移除。
- [x] **清单覆盖和诊断完善**。已接入 ZCode 用户插件登记。豆包的本地清单来源尚无可复核依据，明确标记未覆盖。已在 DSH Desktop 验证登记缺失、无记录、读取成功和解析失败。
- [x] **界面整理**。按应用查看资源和 Skills 简介，按需展开路径及诊断。在 DSH 验证 360px 面板布局、键盘操作、滚动、焦点返回及深浅色主要文本对比度。
- [ ] **发布验收**。rc.20 已通过本地及 GitHub Actions 完整检查。在独立 DSH 从安装包安装、检查页面、恢复两版 Skills、卸载并回退 rc.19。剩余包括两版 Qoder 客户端刷新、兼容性验收和稳定版发布。
